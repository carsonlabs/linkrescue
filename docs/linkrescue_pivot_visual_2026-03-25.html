LinkRescue Visual Decision Memo
Verdict: Readjust, then scale

The API pivot looks real. The current pricing does not.

LinkRescue has a real wedge in affiliate link health infrastructure, but the current $79 Agency offer is too cheap if customers use the API seriously. The biggest risk over the next 6 months is not cloud spend alone. It is reliability, scan throughput, and underpriced heavy usage.

$45-$85 current monthly base burn
$99-$149 recommended new API tier
$249+ recommended true agency infra tier
Why it works
  • Clear market demand
  • API-first whitespace still exists
  • Pro plan economics are healthy
What must change
  • Stop selling cheap unlimited-ish API usage
  • Meter crawl pages and URL checks
  • Move heavy scans off request-bound workers
Biggest risks
  • 5-minute worker cap
  • Serial scan execution
  • Bot blocking and egress concentration

Recommendation
